# Loro Parque B2B — Prototipo Demo

Proyecto demo de portal B2B de venta de entradas para
agencias del hotel **Bahía del Duque** (The Tais Hotels).

Simula la compra de entradas para Loro Parque y Siam Park.

## Rama de trabajo

El prototipo interactivo está en la rama `demo`.

## Ejecución

```bash
git checkout demo
python3 -m http.server 3030
```

→ http://localhost:3030
